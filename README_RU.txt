DOMINION — стартовая версия

Сейчас бот:
- распознаёт формат стандартного российского гражданского номера;
- определяет региональный код по встроенному справочнику;
- не выдумывает марку и модель.

Для определения марки/модели по номеру нужен легальный и надёжный источник
данных с разрешением на такое использование. Единой открытой базы всех
российских номеров для такого поиска нет.

Запуск на компьютере или облачном хостинге:
1. Python 3.11+
2. pip install -r requirements.txt
3. Задать переменную окружения BOT_TOKEN (токен от BotFather).
4. python bot.py

Токен никому не пересылай и не публикуй. Для круглосуточной работы нужен
облачный хостинг. Сам архив не размещает бота в интернете автоматически.
